Optic flow in the sensorimotor block is generated by the animal's own locomotion, so a stationary animal has no flow to decouple and a mismatch event is not a stimulus. A trial qualifies as running when mean forward speed reaches the selected threshold in both the 343 ms pre-event window and the mismatch window.
